### The command {#hotkey}

The command is named after your app: with Typora it reads **Open current file in Typora**. Run it from the command palette, or give it a shortcut in Settings → Hotkeys. If you change the app, the new name shows in the command after Obsidian restarts.

### The ribbon button {#ribbon}

The plugin also adds a button to the ribbon, an arrow pointing out of a box, that does the same as the command. On desktop it sits in the ribbon on the left. Right-click the ribbon to hide or show it, and drag it to move it.

### The mobile quick menu {#mobile-menu}

On iPhone and iPad, add the button to the quick-access menu under Settings → Appearance → **Ribbon menu configuration**. It's listed under the command's name, such as **Open current file in Textastic**.
