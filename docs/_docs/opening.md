### The command {#hotkey}

**Open current file in…** is named after your app, such as **Open current file in Typora**. Give it a shortcut under Settings → Hotkeys. After changing the app, restart Obsidian to update the name.

### The ribbon button {#ribbon}

The ribbon button, an arrow out of a box, does the same. On desktop, right-click the ribbon to hide or show it. On iPhone and iPad, add it to the quick-access menu under Settings → Appearance → **Ribbon menu configuration**.
