### FAQ {#faq}

**iA Writer opens an empty document instead of my note.**

The **Location** setting doesn't match the Location's name in iA Writer. Check spelling and capitals.

**The command still shows the old app's name.**

Restart Obsidian after changing the app.

### Feedback and contributing {#feedback}

Open With App is tested on macOS and iOS only. If you use it on Windows or Linux, or with an app that needs a custom link, I'd like to hear how it goes. [Open an issue](https://github.com/i-am-fran/obsidian-open-with-app/issues) for bugs and feedback. Pull requests are welcome too.
