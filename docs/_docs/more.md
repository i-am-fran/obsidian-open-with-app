### FAQ {#faq}

**iA Writer opens an empty document instead of my note.**

The **Location** setting doesn't match the name of the Location in iA Writer. Check the spelling and capitals, exactly as iA Writer shows it.

**The command still shows the old app's name.**

The name is set when Obsidian starts. Restart Obsidian after changing the app.

**Can I use another app than iA Writer on iPhone and iPad?**

Yes, if the app has a link that opens a file. On iOS, Obsidian can't start other apps directly, only open links. Textastic is built in. For others, choose **Custom link** and enter the app's link: see [Other apps on iOS](#app-ios-custom).

**Does it work on Android?**

No. On Android the plugin shows a notice that it can't open other apps there.
