### Opening {#features-opening}

- One command, named after your app
- A ribbon button, also in the mobile quick-access menu

### Devices {#features-devices}

- Mac: any app by name
- Windows: any program by path
- Linux: any command
- iOS: iA Writer (with or without the keyboard), Textastic, or any app's link
- iOS: setup steps for the chosen app
- A separate app per kind of device

### Notices {#features-notices}

- No note open
- No app chosen, or not set up yet
- macOS can't find the app
- The app fails to start
- Android isn't supported
