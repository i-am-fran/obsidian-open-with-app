# Changelog

## 2026.11.1

- Added a ribbon icon for the command. On mobile you can now add it to the quick-access menu under Settings → Appearance → Ribbon menu configuration. On desktop you can hide the icon by right-clicking the ribbon.

## 2026.10.2

- Fixed: on Mac, Windows and Linux the command did nothing in 2026.10.1. It now opens the note in your app again.

## 2026.10.1

- First release: a command that opens the current file in another app. On Mac you name the app, on Windows you give the program's path, on Linux the command, and on iOS the iA Writer Location that holds your vault. Each kind of device keeps its own setting, so a synced vault works everywhere.
